# Pengenalan Malware Analysis

## Deskripsi

Pada pembelajaran minggu kelima, saya mempelajari konsep dasar **Malware Analysis**, yaitu proses menganalisis perangkat lunak berbahaya (malware) untuk memahami cara kerja, tujuan, serta dampaknya terhadap sistem komputer. Materi ini juga membahas jenis-jenis malware, tujuan analisis malware, serta metode analisis yang umum digunakan dalam bidang keamanan siber.

---

## Tujuan Pembelajaran

Setelah mempelajari materi ini, saya diharapkan mampu:

- Memahami pengertian malware dan malware analysis.
- Mengenal berbagai jenis malware beserta karakteristiknya.
- Memahami tujuan dilakukannya malware analysis.
- Mengetahui metode analisis malware.
- Memahami pentingnya malware analysis dalam Cyber Security.

---

## Materi yang Dipelajari

### Pengertian Malware

Saya mempelajari bahwa **Malware (Malicious Software)** adalah perangkat lunak yang dibuat dengan tujuan merusak, mencuri informasi, mengganggu sistem, atau memperoleh akses tanpa izin ke suatu perangkat.

---

### Jenis-Jenis Malware

Saya mempelajari beberapa jenis malware yang umum ditemukan, antara lain:

- Virus
- Worm
- Trojan
- Ransomware
- Spyware

Setiap jenis malware memiliki karakteristik dan cara penyebaran yang berbeda.

---

### Malware Analysis

Saya mempelajari bahwa Malware Analysis merupakan proses untuk memahami perilaku, fungsi, dan tujuan suatu malware tanpa harus menjalankannya pada sistem produksi.

Tujuan utama malware analysis meliputi:

- Mengidentifikasi jenis malware.
- Memahami cara kerja malware.
- Mengetahui teknik penyebaran malware.
- Mengidentifikasi indikator kompromi (IoC).
- Membantu proses mitigasi dan penanganan insiden.

---

### Metode Malware Analysis

Saya mempelajari beberapa metode analisis malware, yaitu:

- **Static Analysis**, yaitu menganalisis malware tanpa menjalankannya.
- **Dynamic Analysis**, yaitu menganalisis perilaku malware saat dijalankan di lingkungan yang aman.
- **Hybrid Analysis**, yaitu menggabungkan static analysis dan dynamic analysis untuk memperoleh hasil yang lebih lengkap.

---

### Lingkungan Analisis

Saya mempelajari bahwa analisis malware sebaiknya dilakukan pada lingkungan yang aman, seperti:

- Virtual Machine (VM)
- Sandbox

Hal ini bertujuan untuk mencegah malware menginfeksi sistem utama.

---

### Tools Malware Analysis

Saya mengenal beberapa tools yang umum digunakan dalam malware analysis, di antaranya:

- Ghidra
- Wireshark
- Procmon

---

## Hasil Pembelajaran

Setelah mempelajari materi ini, saya dapat:

- Memahami konsep dasar malware serta berbagai jenis malware yang umum ditemukan.
- Menjelaskan metode analisis malware, yaitu Static Analysis, Dynamic Analysis, dan Hybrid Analysis.
- Mengenal tools dan lingkungan yang digunakan untuk melakukan malware analysis secara aman.

## Kesimpulan

Materi **Pengenalan Malware Analysis** memberikan pemahaman dasar mengenai malware, metode analisis, serta tools yang digunakan untuk menganalisis perangkat lunak berbahaya. Pengetahuan ini menjadi fondasi penting sebelum mempelajari teknik analisis malware secara lebih mendalam menggunakan metode **Static Analysis** dan **Dynamic Analysis** pada pertemuan berikutnya.
