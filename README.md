# Reverse Engineering Learning Journal

Repository ini berisi dokumentasi proses pembelajaran saya selama mempelajari **Reverse Engineering**. Setiap minggu berisi materi yang dipelajari, praktik yang dilakukan, hasil analisis, serta Worklog sebagai dokumentasi perkembangan pembelajaran.

---

## Deskripsi

Reverse Engineering adalah proses menganalisis perangkat lunak tanpa memiliki akses ke source code untuk memahami cara kerja, struktur, dan perilaku program. Repository ini dibuat sebagai Learning Journal untuk mendokumentasikan seluruh proses pembelajaran, mulai dari teori hingga praktik analisis menggunakan berbagai tools Reverse Engineering.

---

## Tujuan

Repository ini dibuat dengan tujuan untuk:

- Mendokumentasikan proses pembelajaran Reverse Engineering.
- Menyimpan hasil praktik dan analisis yang telah dilakukan.
- Menjadi referensi pribadi untuk mempelajari kembali materi.
- Membangun portofolio pembelajaran di bidang Cyber Security.
- Melatih kemampuan dokumentasi teknis menggunakan GitHub.

---

## Isi Repository

Repository ini berisi:

- Ringkasan materi setiap pertemuan.
- Worklog hasil praktik.
- Hasil analisis Reverse Engineering.
- Dokumentasi penggunaan tools.
- Screenshot proses analisis.
- Catatan dan kesimpulan pembelajaran.
